# List of Components

## What platform and file type do we use?

For the list of components, we use the following file formats:
1. **SVG** to create vector-scalable images that don’t lose quality when zoomed in
2. **PNG** because it is one of the most common image standards for general use

The diagrams showing all the materials were created on the **Excalidraw** platform because it is *open source*;
you can access it via the link *https://excalidraw.com/*

## Why do we use these components?

Among the most notable components of our project, we highlight the use of
- **Nvidia Jetson AGX Orin**: This is the device that runs the AI models locally and performs most of the heavy-duty calculations;
we utilize acceleration and optimization through the ***CUDA*** platform to take advantage of the GPU
- **HMI Display**: As Human-Machine Interface technology, it enables interactive experiences since it acts as both an
input and output device at the same time
- **ESP32**: This is the microcontroller we use in each of our units because it allows us to utilize the
**IoT** platform natively; furthermore, its 240 MHz clock speed enables us to perform heavy computations
